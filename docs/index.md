# Git and GitHub Documentation

Welcome to this documentation website about **Git and GitHub**. It introduces version control, explains a basic workflow, and answers common beginner questions.

## What is version control?

Version control is a system that records changes to files over time. It helps developers review previous versions, collaborate with others, and recover from mistakes.
