Usage Guide

Learn the basic commands used in Git.

Home Usage Guide FAQs

1. Initialize a Repository

Use this command to initialize Git in a project folder.

git init

2. Check Repository Status

Check which files have been changed.

git status

3. Stage Changes

Add files to the staging area before committing.

git add .

4. Commit Changes

Save a snapshot of your staged changes.

git commit -m "My changes"

5. Push Changes

Upload your commits to the remote repository.

git push
