Frequently Asked Questions

Common questions about Git and GitHub.

Home Usage Guide FAQs

1. What is Git?

Git is a version control system that tracks changes in files.

2. What is GitHub?

GitHub is an online platform for hosting Git repositories and collaborating on projects.

3. What is a repository?

A repository stores project files and their version history.

4. What is a commit?

A commit records a set of changes in the repository's history.

5. What is GitHub Pages?

GitHub Pages hosts static websites directly from a GitHub repository.
