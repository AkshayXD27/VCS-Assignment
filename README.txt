GitHub Pages assignment starter files

1. Create a public GitHub repository.
2. Upload the docs folder from this archive to the repository root.
3. In the repository, open Settings > Pages.
4. Set the source to Deploy from a branch, choose main and /docs, then Save.
5. Wait for publishing to finish and open the URL shown in Settings > Pages.
6. Test the home page and the links to usage.md and faq.md.

The Markdown pages are starter content; edit the title/content if your instructor gave you a specific project topic.
